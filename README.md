# 意绘 · IntentCanvas

探索人与 AI 如何共同进行视觉创作和编辑。初期聚焦 PPT 与矢量图，减少反复描述位置、传输文件和返工的成本。

## 初期场景与交互设想

- 文字配合粗略框选：表达修改范围，由 AI 推断目标。
- 精确选择对象：直接指定修改对象与要求。
- 手动编辑与 AI 修改自然接续，保留编辑上下文。
- 提供清晰的对象指向、修改反馈与撤销能力。

以上均为待验证的交互设想，尚无功能实现。

## 已确定方向

- 优先本地开发与使用，以网页作为交互界面；云端部署后续评估。
- 探索适合 AI 理解和局部编辑的结构化中间表示。
- 目标输出 SVG 与可编辑 PPT；格式保真度与支持范围待验证。
- 重视对象指向、修改反馈、手动与 AI 编辑接续及撤销。

这些是探索方向，不代表技术选型已经确定。
