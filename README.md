# 意绘 · IntentCanvas

探索人与 AI 如何共同进行视觉创作和编辑。初期聚焦 PPT 与矢量图，减少反复描述位置、传输文件和返工的成本。

## 初期场景与交互设想

已确定提供两种可选入口：在意绘中生成初稿后持续编辑，或打开已有 PPT 直接修改。两者均为产品需求，尚未实现；导入支持范围待讨论。

- 文字配合粗略框选：表达修改范围，由 AI 推断目标。
- 精确选择对象：直接指定修改对象与要求。
- 手动编辑与 AI 修改自然接续，保留编辑上下文。
- 提供清晰的对象指向、修改反馈与撤销能力。

以上均为待验证的交互设想，尚无功能实现。

## 需求与探索方向

- 保留本地开发与验证的方向；产品形态重新比较插件、本地伴随程序和嵌入式 Web App，尚未选择。此前的独立网页方案作为候选保留。
- 探索适合 AI 理解和局部编辑的结构化表示；同时比较保留宿主原生文档、只向 AI 提供任务所需视图的方案。
- 目标输出 SVG 与可编辑 PPT；保留并允许深入编辑文件格式中定义的子对象，复杂对象仅能整体操作不满足要求。具体覆盖情况与保真度待验证。
- 重视对象指向、修改反馈、手动与 AI 编辑接续及撤销。

对象编辑等需求已经明确，产品形态与技术方案尚未确定。
